Full Stack & Mobile Developer con IA aplicada · Salta, Argentina (UTC-3)

Construyo productos de punta a punta: web en React, backend en Node.js/TypeScript, mobile en Flutter y LLMs integrados donde suman.

## Proyectos destacados

- **[Escudo Live](https://github.com/Gabyresina15/desafio-qualydata-streaming)**: 3.er puesto, Hackathon Argentina Space 2026 (track QualyData Streaming). Plataforma en Python sin dependencias externas para órdenes de bloqueo en vivo de transmisiones: evidencia con hash SHA-256, firma judicial por turno, despacho paralelo a proveedores con reintentos y backoff, y auditoría encadenada. 10 tests y CI.
- **[Detección de narrativas y coordinación](https://github.com/Gabyresina15/desafio-qualydata-bigdata)**: Hackathon Argentina Space 2026 (track QualyData Big Data). Pipeline en Python con DuckDB, Parquet, embeddings locales y Leiden que detecta narrativas, su fecha de origen y cuentas coordinadas. 53,57/55 en el puntaje automático del evaluador oficial sobre el set de práctica (línea base: ~17). Tests y CI.
- **[Kinetix OS](https://github.com/Gabyresina15/kinetix-os)**: proyecto presentado al Meta Global AI Developer Hackathon. Fastify 5 + React 19/Vite 8. Ejecuta código generado por el modelo en un sandbox QuickJS (WASM), con tope de gasto que pide autorización por voz, registro de operaciones con hash y opción de deshacer.
- **[FactuPipe](https://github.com/Gabyresina15/FactuPipe)**: extracción de facturas argentinas. Primero aplica reglas (incluido el checksum del CUIT) y un LLM local (Llama 3.2 1B) completa lo que falta. Express, MongoDB, Zod, CI con GitHub Actions.
- **[RondaPro](https://github.com/Gabyresina15/RondaPro)**: app Flutter + API en Fastify con JWT. Resume con Gemini en menos de 10 s y, si el modelo no responde a tiempo, usa un resumen heurístico de respaldo.
- **[ios-wearos-ancs-bridge](https://github.com/Gabyresina15/ios-wearos-ancs-bridge)**: lleva las notificaciones del iPhone a un Galaxy Watch (Wear OS) por BLE/ANCS. App en Kotlin, probada en un reloj real. CI en verde.
- **[AgenticHub](https://github.com/Gabyresina15/AgenticHub)**: genera clases con un agente en Gemini que busca en la web con tool calling y devuelve JSON validado con Zod. React + Express + MongoDB.
